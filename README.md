# UDF_ESTRUTURA_DE_DADOS_II

Repositório com os códigos, exercícios e atividades práticas da disciplina de **Estruturas de Dados II**.

## Sobre a disciplina

Nesta disciplina, aprofundamos os conhecimentos sobre **estruturas de dados não lineares**, fundamentais para a organização, o armazenamento e a manipulação eficiente de informações no desenvolvimento de software.

Ao longo do curso, são estudados os principais conceitos, algoritmos de manipulação e aplicações práticas dessas estruturas, além dos desafios envolvidos em sua implementação, utilização e análise.

## Objetivos

Ao final da disciplina, espera-se ser capaz de:

- compreender os principais conceitos relacionados às estruturas de dados não lineares;
- identificar diferentes estruturas e suas características;
- analisar problemas que envolvem a manipulação dessas estruturas;
- implementar e utilizar estruturas de dados de maneira adequada;
- avaliar soluções considerando eficiência e desempenho;
- aplicar os conhecimentos na resolução de problemas computacionais.
